# 0006. Ставка НДС из справочника 1С

- Статус: принято
- Дата: 2026-09-13

## Контекст

В справочнике `Catalog_СтавкиНДС` 9 ставок: «Без НДС», «0%», «10%», «10/110», «20%», «20/120», «22%», «22/122» и «13%». У каждой есть число `Ставка` и признак `Расчетная`.

В 2026 году в НК РФ основная ставка 22%, льготная 10%, есть 0%, а на УСН — 5% и 7%. Ставки 13% в налоговом кодексе нет: это та самая «нетиповая» ставка, про которую предупреждает задание. Ставки 20% и 20/120 остались в справочнике с прошлого года.

Задание говорит прямо: начислять НДС сверху или выделять из суммы, решает флаг в шапке заказа, а не название ставки. В эталоне ставка «22/122» в заказе без флага начисляется сверху.

## Варианты

- **Таблица ставок в коде** (`"22%" → 22`, `"22/122" → выделить`). Ломается на 13%, на любой новой ставке и на правиле «решает флаг».
- **Разбор названия** (`"22/122"` → 22 и «выделить»). Та же проблема плюс хрупкость: название — текст для человека.
- **Число `Ставка` по ключу строки, способ — по флагу заказа.**

## Решение

Для каждой строки заказа берём `СтавкаНДС_Key`, находим ставку в справочнике и используем её поле `Ставка` как есть. Название (`Description`) идёт только в документ (`vatName`). Признак `Расчетная` на расчёт не влияет. Способ задаёт `ЦенаВключаетНДС` заказа:

- флаг снят: НДС = сумма × ставка / 100, сумма с НДС = сумма + НДС;
- флаг поднят: НДС = сумма × ставка / (100 + ставка), сумма с НДС = сумма.

Справочник читается при каждой операции, без кэша ([0009](0009-no-cache.md)).

## Последствия

- Новая или нетиповая ставка в 1С работает без изменения кода; дробная ставка тоже считается точно.
- Если ключа ставки строки нет в справочнике, строка не считается с 0%, а операция завершается ошибкой `ONEC_DATA_INCONSISTENT` с номером строки. Молчаливый ноль хуже явной ошибки.
- Тесты: 13%, «22/122» в заказе без флага, флаг поднят при ставке «22%», дробная ставка, неизвестный ключ.
