# 0001. Go и страница без сборки

- Статус: принято
- Дата: 2026-09-13

## Контекст

Стек в задании свободный. Работу поднимают у себя одной командой, смотрят экран, документ и читают код. Сервис почти целиком состоит из разговора с чужой системой по HTTP: таймауты, повторы, отмена по дедлайну. Экран — одна страница, дизайн не оценивается.

## Варианты

- **Go.** HTTP-сервер и клиент, контекст с дедлайнами и `embed` есть в стандартной библиотеке. Результат — один статический бинарник. Минус: PDF-библиотеки беднее, чем в Python или Node, таблицу приходится рисовать самим.
- **Python + FastAPI.** Готовые библиотеки для PDF и склонения. Минус: образ тяжелее, асинхронные таймауты и отмена требуют больше внимания.
- **Node.js + TypeScript.** Хорошие библиотеки. Минус: числа по умолчанию float, для денег это ловушка на каждом шагу.
- **OneScript (язык 1С).** Близко к профилю вакансии. Минус: нет ни PDF, ни склонения, пришлось бы тащить Chromium в контейнер.
- **Фронт на React или Vue.** Минус: отдельная сборка и Node в образе ради одной страницы с формой.

## Решение

Go 1.25, `net/http` из стандартной библиотеки. Страница — обычные HTML, CSS и JS, вшитые в бинарник через `embed`.

## Последствия

- Сервис и страница — один файл, образ маленький, запуск `docker compose up`.
- Таблицу в PDF рисуем сами поверх `signintech/gopdf`.
- Для склонения хорошего готового пакета на Go нет, см. [0010](0010-name-declension.md).
- Страница простая, без фреймворка. Если экран разрастётся до нескольких страниц, решение стоит пересмотреть.
