# 0010. Склонение ФИО

- Статус: принято
- Дата: 2026-09-13

## Контекст

В документе ФИО получателя стоит в родительном падеже: «Выдать Воронцова Петра Аркадьевича». Задание даёт четыре контрольных клиента, подобранных нарочно: несклоняемые «Коваленко» и женская «Седых», женская «Синицына», «Пётр» с беглой гласной. Если `gender` не пришёл, пол определяется по отчеству.

Задание разрешает брать готовую библиотеку. Стандарт де-факто для русских ФИО — проект petrovich: набор правил `rules.json` (MIT) и порты на разные языки.

## Варианты

- **Порт на Go `an112chuh/Petrovich-Go`** (и форк `fyrolab`). Версия 0.0.1, заброшен. Все четыре эталона проходят, но проверка на соседних случаях нашла ошибку: если подходящее правило велит оставить слово без изменений, порт не останавливается и берёт следующее. Мужская «Седых» превращается в «Седыха». Правила в порту устаревшие, но с официальными ошибка та же: она в выборе правила, а не в данных.
- **Порт с исправлением внутри форка.** Чиним одну строку, но тянем за собой остальной код порта и его API: правила загружаются только из файла на диске.
- **Официальные правила и свой выбор правила.** Правила берём из `petrovich-rules` как есть; поиск и применение пишем по эталонной реализации petrovich-js, это около 60 строк.

## Решение

Пакет `internal/infrastructure/petrovich`:

- `rules.json` из `petrovich-rules` (обновлён 2024-11-15) вшит в бинарник, рядом лежит его лицензия;
- правило ищется сначала среди исключений по слову целиком, потом по окончаниям; **первое подходящее правило окончательное**, даже если оно «оставить как есть»;
- двойные имена склоняются по частям, правила с тегом `first_word` действуют только на первую часть («Бонч-Бруевич»);
- пакет реализует доменный порт `person.NameInflector`.

Пол по отчеству определяет домен (`person.GenderFromPatronymic`): -ич и «оглы» — мужской, -на и «кызы» — женский. Если нет ни пола, ни отчества, пол не угадываем по имени (Саша, Женя, Валя), а возвращаем ошибку поля `gender`.

## Последствия

- Тесты фиксируют 4 эталона задания, мужскую «Седых», «Шевчук» в обоих родах, «Римский-Корсаков», «Бонч-Бруевич», «Лев → Льва», «Любовь → Любови», «Гасан оглы».
- Правила — внешние данные: обновить их можно заменой файла без правки кода, тесты сразу покажут регрессию.
- Регистр не нормализуется: «ИВАНОВ» получит окончание строчными буквами. Для формы, где человек вводит ФИО обычно, это приемлемо.
