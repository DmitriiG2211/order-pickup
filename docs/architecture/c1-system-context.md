# C1. Контекст системы

```mermaid
C4Context
  title C1. Выдача заказа со склада
  Person(clerk, "Кладовщик", "Открывает заказ, смотрит остатки, вводит получателя, печатает документ")
  Person(reviewer, "Проверяющий", "Прогоняет автопроверку документа")
  System(service, "Сервис выдачи заказов", "Экран, документ в JSON и PDF, черновик реализации в 1С")
  System_Ext(onec, "1С:УТ 11.5, эмулятор", "OData: заказы, справочники, остатки, реализации")

  Rel(clerk, service, "Работает в браузере", "HTTP")
  Rel(reviewer, service, "POST /api/documents/preview", "HTTP, JSON")
  Rel(service, onec, "Читает заказы и остатки, пишет черновик реализации", "OData, Basic auth")
```

## Что важно на этом уровне

- 1С чужая: исходников нет, починить под себя нельзя. Опубликован только OData, конфигуратор не подключить.
- Учётная запись 1С общая для всех кандидатов. Пять неудачных входов блокируют её на пять минут для всех.
- Данные получателя (ФИО, телефон, почта) живут только в запросе: не сохраняются ни у нас, ни в журнале, ни в 1С.
